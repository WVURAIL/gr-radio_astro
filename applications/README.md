# Research applications

[NSF observing applications](nsf/README.md) record spectra and transient events with software-defined receivers.
Their catalog lists available bandwidth variants, launch instructions, and historical versions.

Classroom applications belong in [DSPIRA software](https://github.com/WVURAIL/dspira-software/tree/main/applications).
Smaller demonstrations and research notebooks belong in [examples](../examples/README.md).

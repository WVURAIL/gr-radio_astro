# Shared observing configuration

Launch the [NSF applications](../README.md) from this directory.
It contains their `.conf` settings, `.not` observation metadata, calibration spectra, and display stylesheet.

The original filenames match observation names inside the applications.
Several Detect and Watch variants share the corresponding Integrate settings.
These names and file contents remain unchanged to preserve that behavior.
Back up your settings before using applications that write updated configuration.
